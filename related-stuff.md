| 3. Core Workflow & Form Mechanics                                                                                                                                                                                                                                                                                                                                                                                                                                                           |                          |
| Almost every form follows a two-step Input → Output workflow to prevent users from accidentally breaking official document layouts:                                                                                                                                                                                                                                                                                                                                                         |                          |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |                          |
| Input Screen: Clicking a dashboard button opens a clean data-entry form with two primary actions:                                                                                                                                                                                                                                                                                                                                                                                           |                          |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |                          |
| ENTER: Transfers the entered data into the official printable template, automatically injecting the school's logos, address, and signatories.                                                                                                                                                                                                                                                                                                                                               |                          |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |                          |
| Clear Entries: Wipes the input fields clean for the next request.                                                                                                                                                                                                                                                                                                                                                                                                                           |                          |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |                          |
| Printable Output Screen: Displays the formatted, print-ready document with a Return to Dashboard button (and, on some forms, a Clear Manual Entries button to reset only the editable fields without touching formulas/templates).                                                                                                                                                                                                                                                          |                          |
|                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |                          |
